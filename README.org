#+title: sub-buffer

A Subsonic player for Emacs. The queue is a buffer; edit it with the tools
you already use.

Requires Emacs 28.1+, =mpv= on PATH, and Linux or macOS.

For standard Emacs, add to your configuration:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/sub-buffer")
(require 'sub-buffer)
(setq sub-buffer-server "https://music.example.org")
#+end_src

For Doom, add to =packages.el=:

#+begin_src emacs-lisp
(package! sub-buffer
  :recipe (:host github :repo "soliprem/sub-buffer.el"))
#+end_src

And to =config.el=:

#+begin_src emacs-lisp
(use-package! sub-buffer
  :commands sub-buffer
  :init
  (setq sub-buffer-server "https://music.example.org"))
#+end_src

Run =doom sync= and restart Emacs. Evil and localleader integration is
automatic.

Use the server's base URL, including any path prefix, without =/rest=.
Login and password come from =auth-source=. For example, in
=~/.authinfo.gpg= (or =~/.authinfo=):

#+begin_example
machine music.example.org login your-username password your-password
#+end_example

Use the hostname or base URL for =machine=. Multiple matching logins prompt
for a choice; set =sub-buffer-user= to choose one explicitly. A missing
password prompts for one.

=M-x sub-buffer-switch-login= chooses another account for this session.

Emacs checks the standard authinfo files by default. If you've customized
=auth-sources=, include the file you use:

#+begin_src emacs-lisp
(add-to-list 'auth-sources "~/.authinfo.gpg")
#+end_src

Open with =M-x sub-buffer=.

| Key         | Action                        |
|-------------+-------------------------------|
| TAB         | Complete a query              |
| RET         | Accept or open a draft        |
| C-c RET     | Accept without opening a line |
| C-c C-c     | Play the entry                |
| C-c C-p     | Previous track                |
| C-c SPC     | Pause / resume                |
| C-c C-n     | Next track                    |
| C-c C-s     | Stop                          |
| C-c <left>  | Seek backward 10 seconds      |
| C-c <right> | Seek forward 10 seconds       |

See =C-h m= for the remaining commands and Evil behavior, and =C-h b= for
active bindings, including localleader.

To use Org for saved playlists:

#+begin_src emacs-lisp
(setq sub-buffer-use-org t
      sub-buffer-playlist-directory "~/org/playlists/")
#+end_src

=M-x sub-buffer-open-playlist= opens or creates a playlist in that directory.
Org files there open as playable queues. =M-x sub-buffer= also uses Org;
save its buffer there to keep the playlist.

Track IDs live in Org links, one per line. The file records its Subsonic
server; playback checks that it matches =sub-buffer-server=.

This is a prototype: search is synchronous, and there's no scrobbling.
Without Org support, saving the queue as plain text loses track references.
